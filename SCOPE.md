# Scope

This repo is the set of skills and plugins I use on real work. It is curated: ideas are welcome, and each one is judged against the bar below. Issues are for tracking changes to the skills. Questions and discussion go to [GitHub Discussions](https://github.com/illiazakirov/skills/discussions).

## The bar

An idea or feedback issue stays open only if it clears **both** parts:

1. **Observed failure.** It describes something that went wrong in a real session: what you ran, what the skill did, what you expected. A hypothetical improvement ("it would be better if...") does not clear this part.
2. **Fits the philosophy.** It is not a config option, a branch for one harness, or a tweak to suit one person's workflow. Those belong in your own `CLAUDE.md` / `AGENTS.md`, or in a copy of the skill (skills.sh gives you an editable one).

Size is irrelevant: a one-word fix and a rewrite face the same bar. Reactions and +1 comments do not count towards it.

A report that a skill fails on an agent or a model it should work on always clears the second part: every skill here is meant to work with any agent and any model.

## Unclear issues

An issue that can't be judged against the bar gets one round of questions and the `needs-info` label. With no reply in 14 days, it is closed.
